# 🐦 Flappy Bird - JavaScript Vanilla

Projeto desenvolvido durante o treinamento do Mario Souto (DevSoutinho) para praticar os conceitos fundamentais de desenvolvimento web, manipulação de DOM e lógica de jogos utilizando JavaScript puro.

---

## 🚀 Sobre o Projeto

Uma recriação do clássico jogo Flappy Bird, rodando diretamente no navegador. O objetivo principal deste projeto foi entender como construir a mecânica de um jogo do zero, gerenciando estados, renderização em tela e detecção de colisões.

---

## 🎯 Conceitos Aprendidos e Praticados

- **Canvas API / HTML5:** Renderização de gráficos 2D e ciclo de animação (`requestAnimationFrame`).
- **Manipulação de Estados:** Controle das telas de início, jogo rolando e Game Over.
- **Lógica de Colisão:** Cálculo de limites e sobreposição de objetos em tela.
- **Efeitos Sonoros:** Integração de áudio para ações como pular e perder.
- **Estrutura de Dados:** Organização do código usando funções construtoras e objetos.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS**
- **JavaScript (ES6+)**
